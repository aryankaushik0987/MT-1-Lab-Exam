# Hospital Patient Management System

## Project Description

A Hospital Patient Management Web Application
developed using Node.js and Express.js.

## Technologies Used

- Node.js
- HTTP Module
- FS Module
- Express.js
- JavaScript
- Postman

## Installation

1. Clone the repository.
2. Open the project folder.
3. Install dependencies:

npm install

## Run HTTP Server

node httpServer.js

Server runs on:
http://localhost:3000

## Run Express Server

node expressApp.js

Server runs on:
http://localhost:4000

## HTTP Routes

GET /
GET /patients
GET /about
POST /add-patient

## Express REST API

GET /patients
GET /patients/:id
POST /patients
PUT /patients/:id
DELETE /patients/:id

## Database

JavaScript Array is used to store patient records.
